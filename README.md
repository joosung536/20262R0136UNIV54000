# MOST WANTED: NIGHT RUN

네온 도시에서 청록색 스포츠카를 몰며 경찰의 추격을 버티는 탑다운 2D 아케이드 게임입니다. HTML5 Canvas, CSS, Vanilla JavaScript만 사용하며 차량과 도시는 모두 도형으로 그립니다.

## 실행 방법

같은 폴더에 `index.html`, `style.css`, `script.js`, `README.md` 네 파일을 두고 **index.html을 더블클릭**하세요. START RUN을 누르면 시작합니다. 인터넷, 서버, 빌드, 패키지 설치가 필요하지 않습니다. 키보드가 있는 최신 데스크톱 브라우저를 사용하세요.

## 조작법

| 키 | 동작 |
| --- | --- |
| W / ↑ | 가속 |
| S / ↓ | 브레이크, 멈춘 뒤 계속 누르면 후진 |
| A, D / ←, → | 좌우 조향 (후진 시 방향 반전) |
| Space | 핸드브레이크 드리프트 |
| Shift + 가속 | 니트로 |
| P / Esc | 일시정지 / 재개 |
| R | 게임 오버 후 재시작 |

정지 상태에서는 차가 제자리 회전하지 않습니다. 가속하며 조향하세요. 코너 진입 전에 감속하고, Space로 차체를 돌린 뒤 놓으면 접지력이 돌아옵니다. 니트로는 직선 탈출에 유리하며 사용하지 않으면 자동 충전됩니다. 완전히 소진되면 Shift를 놓았다 다시 눌러 사용합니다.

## 게임 목표

체력이 0이 될 때까지 최대한 오래 살아남아 최고 점수를 갱신하세요. 25초마다 수배 레벨이 올라가고, 경찰이 1대에서 최대 5대까지 늘어납니다. 경찰은 교차로 경로를 찾아 추적하고 근거리에서 가속합니다. 충돌 피해에는 약 1.15초의 보호 시간이 적용됩니다. 고속으로 건물에 충돌해도 피해를 받습니다.

생존·이동·드리프트로 점수를 얻고, 도로의 노란 다이아몬드를 획득하면 500점이 추가됩니다. HUD 속도는 실제 차량 이동 속도에 비례하는 가상 km/h입니다. 미니맵에서 청록색은 내 차, 빨간색은 경찰, 노란색은 보너스입니다.

최고 점수는 브라우저 localStorage에 저장합니다. 저장이 차단되면 현재 실행 중에만 유지하며 게임은 계속 작동합니다. 탭을 벗어나거나 창이 포커스를 잃으면 자동으로 일시정지합니다. 돌아온 뒤 P 또는 RESUME RUN으로 재개하세요.

## 구현 구조와 제한

- 하나의 requestAnimationFrame 루프, 초당 120회 고정 물리 업데이트, 긴 프레임의 시간 제한.
- 회전 사각형 SAT 충돌, 겹침 보정, 속도 반사, 차량 간 분리 처리.
- 6×6 교차로 그래프의 최단 경로와 시야 판정, 코너 감속 및 막힘 복구.
- 장애물 없는 화면 밖 도로에서 경찰 생성. 화면 밖에서 지나치게 멀어진 경찰은 다른 도로에 재배치될 수 있습니다.
- 외부 라이브러리·이미지·폰트·API·사운드 파일 없이 오프라인으로 실행합니다. 음향과 터치 운전은 제공하지 않습니다.
